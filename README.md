A one-day newspaper front page summing up the world's news of Friday 20 November 2026: hours after the Shenzhen peace summit, Russia fires 110+ missiles at Kyiv in a 10-hour overnight barrage; the Shenzhen declaration rings hollow with no disarmament and no Ukraine breakthrough; the S&P 500 falls ~2% for a fifth straight day while Anthropic debuts ~17% above its $83 IPO price; Saudi Arabia intercepts another Houthi missile; the ICJ rules Myanmar guilty of genocide against the Rohingya; and the US Senate passes a bipartisan energy-permitting bill 62–33. The front page is composed with PIL from a generated lead illustration plus real headlines, set in large type so it stays legible at about 300 pixels across.

## Run it

```sh
python3 main.py
```

`main.py` copies `entry.png` (1024x1024, the front page) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). It runs with no network and writes the same bytes on every run.
